# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python, Jupyter notebooks, and a single local Streamlit page, as requested.

## Users
University students learning introductory traditional machine learning and
presenting an oral examination. The requested priority is easy code and obvious
pipelines, not a bespoke UI framework or a production security product.

## Product Purpose
Make the measured path from real samples through verification, command recognition
and dictionary-based authorization visible and understandable.

## Capabilities and Constraints
Only KNN and linear SVM; no neural recognition or cloud biometric services.
Three enrolled virtual identities combine supplied faces with unrelated public
speaker/finger identities. All protected actions are simulated. Test results,
including rejection and misrecognition, must not be hidden or tuned away.
The requested native Streamlit controls and one-page organization are binding.

## Evidence on Hand
120 supplied portraits; 90 selected genuine Speech Commands recordings;
24 FVC2004 DB1_B impressions; twelve trained classifiers and measured test results.
Real webcam hardware capture has not yet been established in this environment.

## Product Principles
- Show actual model decisions and stop at the first rejection.
- Preserve source identity, split and sample provenance.
- Prefer simple functions and tables over additional abstractions.
- Never mistake authorization correctness for command-recognition accuracy.
